# African Journal Safari Tours: v2

Upgraded version of the site, built to be compared with the current one.

## How to compare
1. Copy your existing `images/` folder into this folder (the photos were not part of the upload, so they are not included).
2. Upload the contents of this folder to a `v2/` folder in your GitHub repository.
3. Open `https://macpaul61.github.io/African_Journal/` (current) and `https://macpaul61.github.io/African_Journal/v2/` (new) side by side.
4. If v2 wins, move its files to the repository root.

## What changed
- Day and night themes (toggle in the header, remembers the choice, follows the device setting at first visit); night has a moving star sky.
- 3D field journal on the homepage hero: it opens on hover, tap or keyboard and links to the four journey themes.
- New palette (acacia green, dusk blue, sunset amber) and fonts (Young Serif + Figtree), taken from your sunset poster.
- Text: nothing below 12px, body 16px, contrast 4.5:1 or better in both themes, 44px touch targets.
- Removed template chrome: tracked all-caps labels, 01/02/03 numbering (kept only for real steps), gold single-word headline accents, arrow glyphs, blur effects.
- Homepage says what you offer in the first screen; the empty "no reviews yet" block is replaced with the 3-step planning process; repeated "packages in development" notes cut to one.
- Contact form: 6 fields instead of 8, errors shown after leaving a field, and the main button now sends the brief on WhatsApp. "Open the enquiry form" opens your Tally form.
- Header call-to-action text is now dark on amber (it was light on gold before).
- Hero video: audio removed, 5.6 MB down to 1.9 MB.
